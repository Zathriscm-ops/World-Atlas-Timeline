# ADR 0004 — Separate uncertainty dimensions

Status: Accepted
Module: M004

Separate evidence strength, chronology, spatial approximation, identity, dispute and review status. Preserve alternatives and explicit unknowns. Reject a universal confidence score, cultural polygons with unqualified control semantics, and uncalibrated numeric probabilities. DEP-11 is resolved at contract level. Rendering/database enforcement remains later work, not claimed complete by this ADR.
