# ADR 0006: Fail closed on unreviewed dataset rights
Status: Accepted, M006, 2026-09-14.

Adopt the seven requested policy classes with separate actual license identifiers, asset scope and review decisions. Rights attach to immutable input versions and propagate through transformations and release manifests. Project code licensing cannot grant rights to external map data.

Positive policy tests use synthetic approvals. The real candidate inventory remains unapproved. DEP-04 now has a concrete acquisition and rights-review path; availability of a historical reviewer and cleared polygons remains a future M028 prerequisite.
